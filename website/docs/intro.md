# 🚀 Getting Started

Ashell is a Wayland status bar written in Rust using the `iced` library. It runs
on any Wayland compositor. See [Compositor Support](./compositor-support.md) for
the dedicated integrations, the generic fallback, and the feature matrix.

## Features

- OS Updates indicator
- Active Window
- Workspaces
- System Information (CPU, RAM, Memory Swap, Disk, Network IP, Download/Upload Speed, Temperature)
- Keyboard Layout (Hyprland/Niri/MangoWC)
- Keyboard Submap (Hyprland/MangoWC)
- Tray
- Date and Time with weather (current time + weather in the bar, calendar + hourly + 7-day forecast in the menu)
- Privacy indicators (microphone, camera, and screen sharing usage)
- Media Player
- Notifications
- Settings Panel
  - Power menu
  - Battery information
  - Audio sources and sinks
  - Screen brightness
  - Network controls
  - VPN
  - Bluetooth
  - Power profiles
  - Idle inhibitor
  - Airplane mode
- Custom Modules (applauncher, clipboard, custom clock, etc.)
